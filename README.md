# Chao HSK Study Studio — мини-сервер

Серверная версия учебной платформы. Сохраняет существующие сценарии приложения и добавляет импорт сканированных PDF:

1. Преподаватель загружает PDF и выбирает уровень HSK 1–9.
2. Сервер сохраняет исходный PDF на постоянном диске и рендерит страницы в изображения.
3. Tesseract распознаёт китайский, русский и английский текст вместе с координатами слов.
4. Для выбранного диапазона страниц Qwen готовит лексику и учебные подсказки.
5. Преподаватель сверяет сканы и OCR, при необходимости исправляет JSON и публикует урок.
6. Опубликованные страницы открываются в платформе как исходные изображения книги с нажимаемыми OCR-словами либо как электронные макеты со строками, размещёнными по координатам оригинала.

Qwen получает только распознанный текст и запросы ученика. Страницы книги остаются на сервере. Оригинальные PDF не выдаются публичными ссылками; опубликованные PNG-страницы доступны читателям платформы.

## Файлы

- **app.html** — исходная платформа со всеми существовавшими вкладками и сценариями; в серверном режиме загружает опубликованные уроки.
- **manager.html** — загрузка, просмотр и публикация урока.
- **server.py** — FastAPI, OCR, хранение библиотеки и обработка с Qwen.
- **Dockerfile**, **requirements.txt** — образ сервера.
- **render.yaml** — конфигурация Render с постоянным диском.


## Развёртывание на Render

1. Создайте приватный GitHub-репозиторий и загрузите в него все файлы этой папки.
2. В Render выберите New → Blueprint, подключите репозиторий и подтвердите сервис chao-hsk-study.
3. При настройке задайте два секретных значения:
   - ADMIN_PASSWORD — длинный пароль для /manage (латинские буквы, цифры и символы).
   - ALI_TOKEN_PLAN_API_KEY — ключ Qwen/Alibaba API. Вставляйте его только в Render, не в исходный код и не в чат.
4. Дождитесь завершения сборки. Главная ссылка сервиса предназначена консультанту и преподавателю. Для своей страницы загрузки добавьте /manage и введите ADMIN_PASSWORD.

Этот пакет настроен на бесплатный Render для пробного запуска. Бесплатный сервер может засыпать после 15 минут бездействия; его файловая система временная, поэтому загруженные PDF, OCR-страницы и уроки могут исчезнуть после сна или перезапуска. Используйте тестовый учебник, который можно загрузить повторно. Для библиотеки с постоянным хранением позже понадобится подключить постоянный диск на платном тарифе либо отдельное объектное хранилище.

## Использование загрузчика

- Поддерживаются сканированные PDF размером до 300 МБ.
- OCR выполняется для всего файла; большой учебник может обрабатываться несколько минут.
- Затем выберите страницы одного урока и подготовьте черновик.
- Для предсказуемых затрат создавайте черновики максимум по 20 страниц за один запрос.
- Сверьте слова, пиньинь, переводы и задания с оригинальным сканом. OCR и модель могут ошибаться.
- После публикации обновите платформу — новый урок появится в списке.

Каждый уровень, включая HSK 7–9, задаётся при загрузке учебника. Книгу можно постепенно делить на уроки, сохраняя исходный вид страниц.

## Практика активного припоминания

- Вкладка «Разбор» → «Практика мысли по-китайски» открывает задание по теме текущего урока и словам из его словаря.
- Ответ можно набрать вручную или надиктовать через голосовой ввод клавиатуры.
- Серверный endpoint отправляет ответ в настроенный Qwen для проверки смысла и грамматики, предлагает исправленный вариант и короткое пояснение.
- После попытки можно повторить фразу и выбрать интервал: завтра, через 3 или 7 дней. Если пока трудно — повтор будет завтра.
- Расписание повторений пока хранится в localStorage этого браузера; оно не синхронизируется между устройствами.
- Для проверки нужен `ALI_TOKEN_PLAN_API_KEY`, уже настроенный в Render. Не помещайте ключ в GitHub.


## Локальный запуск разработчиком

Нужны Docker и переменные окружения ALI_TOKEN_PLAN_API_KEY, ADMIN_PASSWORD и CHAO_DATA_DIR. Образ устанавливает Tesseract с языками chi_sim, rus, eng. Для локального запуска соберите Dockerfile и запустите образ, пробросив порт 8000 на 10000 и подключив постоянный Docker volume к /var/data.

Главная страница после запуска будет доступна на localhost:8000, загрузчик — на localhost:8000/manage.
# Электронные страницы учебника

Загрузка книги работает постранично: сначала загрузите PDF (для первого опыта — PDF с одной страницей), дождитесь OCR и выберите учебник. Введите одинаковый номер в полях «Первая» и «Последняя страница».

- **Подготовить интерактивный скан** сохраняет исходную страницу и существующие упражнения со словарём.
- **Сделать электронную страницу** группирует слова OCR в строки, сохраняет их положения на странице и переводит распознанные английские строки на русский через настроенный Alibaba Cloud Model Studio/Qwen API. Русский текст виден первым; кнопка на странице переключает его на английский оригинал.
- Перед публикацией сравните результат со сканом и поправьте черновик. Необычные шрифты, сложные таблицы и ошибки OCR могут потребовать ручной правки.
- Иллюстрации можно загрузить в PNG, JPG или WebP (до 20 МБ), сохранить в библиотеке выбранного учебника и вставить в электронную страницу. Положение и размер задаются в процентах от страницы. Изображения хранятся рядом с PDF учебника.

Электронный формат рассчитан на список страниц: в дальнейшем диапазон можно обрабатывать партиями, не меняя формат каждой страницы. Исходный скан остаётся доступен для проверки. Новый ключ Alibaba Machine Translation не нужен — перевод вызывается через уже используемые `ALI_TOKEN_PLAN_API_KEY` и `QWEN_MODEL`. Это текстовый вызов Qwen, а не API генерации видео Wan.

Локальные проверки: `python -m unittest discover -s tests -v` и `node --test tests/*.test.cjs`.

# Публикация из Forma Studio

Forma Studio — консоль управления платформой. В ней учебник постранично превращается в веб-страницы (макет, шрифты, цвета, пиньинь, видео и аватары персонажей), страница проверяется и правится, а кнопка **«Подтвердить и опубликовать»** отправляет её сюда.

- Страница попадает в раздел (например, **HSK 1 v3.0**) и в урок по номеру урока учебника: страница-заставка урока открывает урок, следующие страницы до новой заставки входят в него. В списке уроков платформы разделы показаны группами.
- На странице работают обычные сценарии платформы: таблица «Словарь урока» и карточки (из таблицы новых слов страницы), задание, подсказка Сяо Чао, сборка фразы из слов первой реплики, репетитор с контекстом реплик. Слова урока на странице нажимаются, реплики озвучиваются по клику, есть переключатели «Русский / Оригинал / Пиньинь».
- Повторная публикация заменяет страницу; «Снять страницу с платформы» удаляет её.

Настройка:
1. В Render добавьте секрет **FORMA_PUBLISH_TOKEN** — длинную случайную строку (не храните её в GitHub).
2. В Forma Studio → PDF → Web → «Платформа Chao HSK Study» → «Настройки» укажите адрес сервиса и этот токен, проверьте связь.

API (для Forma Studio, с заголовком `Authorization: Bearer <FORMA_PUBLISH_TOKEN>`; пароль преподавателя через Basic тоже принимается):
- `POST /api/forma/pages` — multipart: `meta` (JSON описания страницы), `html`, `css`, `script`, `files[]`;
- `GET /api/forma/pages/{книга}` — что опубликовано; `DELETE /api/forma/pages/{книга}/{страница}` — снять;
- файлы страниц, общие стили и аватары раздаются по `/forma/...`.

Файлы хранятся в `CHAO_DATA_DIR/forma`. На бесплатном тарифе Render диск временный: после перезапуска сервиса страницы нужно опубликовать заново (в студии это одна кнопка для диапазона) — либо подключите постоянный диск.
